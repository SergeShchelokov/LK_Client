# Мой профиль · Личный кабинет

[Открыть приложение](https://sergeshchelokov.github.io/LK_Client/)

Панель профиля из [Figma](https://www.figma.com/design/sgUMYc9xGVmS7UvEG4wUVU/%D0%9B%D0%9A?node-id=9248-35596) на Vue 3 и headless-компонентах `@vuetify/v0`. Открывается через меню аватарки в шапке. Во вкладке «Расслабиться» работает «Трюфолс». Игрок начинает за TRUE, компьютер отвечает за FALSE. Для победы нужны четыре отметки подряд на поле 6×6. Компьютер просчитывает по два хода за каждого игрока и учитывает вилки.

Поля и выбранная аватарка сохраняются в текущем браузере. Подтверждение удаления очищает эти локальные данные. Проверка нового пароля демонстрационная: у статического сайта нет учётных записей и серверного API.

```sh
npm ci
npm test
npm run dev
```

Для обновления сайта выполните `npm run build:pages` и добавьте изменения в `docs/` в коммит. Источник GitHub Pages — ветка `main`, папка `/docs`.
